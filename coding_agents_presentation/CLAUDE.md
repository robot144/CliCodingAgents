# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A [Quarto](https://quarto.org/) reveal.js presentation about coding agents (Claude Code, Copilot CLI, Codex CLI, Mistral Vibe CLI, Gemini CLI) and their use at Deltares. The presentation is built from `index.qmd` and rendered to `index.html`.

## Rendering

At the start of a session, ask the user whether they want **preview mode** (live reload) or **generate mode** (one-shot render), and remember their choice for the rest of the session.

```bash
# One-shot render (generate mode)
./quarto_to_html.sh

# Live preview — auto-reloads in browser on every save (preview mode)
./quarto_preview.sh
```

Both scripts work from the presentation folder or the project root. They try pixi first, then fall back to a system quarto. Quarto is provided through the workspace-level pixi environment (`../pixi.toml`). Run `pixi install` in the workspace root before first use. The `.pixi` environment must be built locally — do not copy it between machines, as quarto's wrapper script embeds absolute paths.

## Presentation structure

- `index.qmd` — source file (edit this, not `index.html`)
- `index.html` — rendered output (regenerated by `quarto_to_html.sh`)
- `figures/` — images used in slides (e.g. `deltares_logo.png`)
- `index_files/` — reveal.js assets copied by quarto on render (do not edit)

## Key settings (in `index.qmd` front matter)

| Setting | Current value |
|---|---|
| Theme | `dark` |
| Logo | `figures/deltares_logo.png` (bottom-right on every slide) |
| Slide numbers | enabled (`c/t` format) |
| Format | `revealjs` |

Add new slides as `## Slide Title` sections in `index.qmd`. Re-run `./quarto_to_html.sh` after every edit.
